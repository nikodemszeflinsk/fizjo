# System pozyskiwania pacjentów dla fizjoterapeutów — Studio Widok

Strona produktu: strona z rezerwacją online, widoczność w Mapach Google i automatyczne przypomnienia SMS dla gabinetów i klinik fizjoterapii. Reklamy Google i Meta jako opcja.

- **Landing page:** `index.html` — oferta: strona z rezerwacją, wizytówka Google, opcjonalne reklamy, w wyższym pakiecie panel CRM
- **Demo strony kliniki:** `demo.html` — przykładowa klinika „Linia Ruchu” z działającą (symulowaną) rezerwacją wizyt i mapą gabinetów
- **Demo CRM:** `crm.html` — panel rejestracji: pulpit, kalendarz tygodnia, kartoteka pacjentów, skrzynka i automatyzacje
- **Wersja do druku:** `karta-produktu.pdf`
